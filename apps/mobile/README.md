# Mobile app

Expo + Expo Router client. See the root [README](../../README.md) for setup and
[`docs/plans/phase-5-mobile.md`](../../docs/plans/phase-5-mobile.md) for the screens planned here.

```bash
cp .env.example .env   # set EXPO_PUBLIC_API_URL
pnpm dev               # expo start
```

Add native dependencies with `npx expo install <package>` so versions match the Expo SDK.
